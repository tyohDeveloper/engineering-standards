# Standards Release VERSION

## Meaning

Explain the semantic change, readiness, authority, and why the version changed.

## Scope and decisions

Changed rules, source documents, ADRs, rejected alternatives, approval.

## Verification

Hub-integrity checks, checker changes/tests, human review, unresolved gaps.

## Adoption effects

Affected applications, required migrations, exceptions, compatibility, and whether an app/data version changes.

## Provenance and Project refresh

Immutable repository/tag/commit references and the Project snapshot source commit.
