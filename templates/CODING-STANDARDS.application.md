# Adopted Coding Standards

Record the approved policy version and immutable source commit. Retain the complete applicable policy locally or define an explicit retrieval step; a hyperlink alone does not prove an agent loaded it.

## Application mapping

Link the application's role/path table and local target profile. Do not copy another application's mapping.

## Enforcement matrix

Map requirements to actual lint, typecheck, tests, build, architecture, data, and artifact commands. Label human-reviewed requirements explicitly.

## Extensions and exceptions

Record owner-approved local additions and exceptions separately from the imported policy. Do not edit a standards copy in isolation from its authority.
