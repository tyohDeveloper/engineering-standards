# Application and Governance Templates

These are starting documents, not automatically adopted instructions.

- [Adoption manifest](STANDARDS-ADOPTION.json): exact version/source/enforcement metadata.
- [Application architecture](ARCHITECTURE.application.md): role/path ownership and boundaries.
- [Application coding guidance](CODING-STANDARDS.application.md): adopted policy and local checks.
- [Application agent guidance](AGENTS.application.md): cross-agent contract.
- [Exceptions](EXCEPTIONS.md): policy deviations separate from standing mandates.
- [ADR](ADR.md): decision, alternatives rejected, consequences.
- [Release meaning](RELEASE.md): version scope and adoption effects.

Copy only after reviewing the actual application. Replace placeholders and keep local architecture, exceptions, targets, and enforcement explicit.
