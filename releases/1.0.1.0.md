# Standards Release 1.0.1.0

Status: released 2026-10-30; tag `standards-1.0.1.0` points at the release-note finalization commit that follows merge commit `8883835` on `main`. Third-component change: smaller substantive fixes from the first adoption pilot, no change to profiles, classes or authority.

## Meaning

Four refinements learned from adopting 1.0.0.0 in OmniUnitConverter-Calculator (PR #2, commit `03a94b4`):

- **C-43 clarified.** Formatting through the mandated binding with injected locale satisfies the rule from PURE; a PLATFORM-PURE role split is optional. Removes a bookkeeping exception (OmniUnit E-6) that had no behavioural content.
- **CI runner pinning (C-19, TypeScript binding).** A floating `ubuntu-latest` image moved to Ubuntu 26.04 and broke Playwright installs before any test ran. Runner images are pinned to a versioned image with a review note; the compliance review checks it.
- **Existing carve-outs prompt.** Pre-existing lint overrides mapped cleanly to C-27 exceptions in the pilot, but only because the adopter looked for them. The exceptions template now asks for them explicitly; the compliance review treats an unmatched inline carve-out as a finding.
- **Adoption provenance.** Adoption records carry `applicationCommit` and `applicationPullRequest`, matching what the hub actually recorded for OmniUnit.

## Scope

`standards/coding-core.md` (C-19, C-43), `standards/bindings/typescript.md` (C-19 row), `templates/EXCEPTIONS.md`, `templates/STANDARDS-ADOPTION.json`, `reviews/standards-compliance-review.md`. No change to `profiles.md`, language classes, or ADRs.

## Verification

`npm run validate` and `npm test` pass. Existing adoption records remain valid (new template fields are optional for records already registered).

## Adoption effects

No application must act. OmniUnit may close E-6 by reference to the clarified C-43. Applications pinning CI runners already comply; others pin at their next adoption or CI change.

## Provenance

Pilot findings: OmniUnitConverter-Calculator PR #2 description and issues #4–#10. Merge commit `8883835`; the tag `standards-1.0.1.0` points at the commit that finalizes this note.
